بوت واتساب لإدارة القروبات (Baileys)

الملفات:
- index.js      كود البوت بكل الأوامر
- package.json  الحزم المطلوبة

التشغيل على Railway:
1) ارفع الملفين على ريبو جديد في GitHub
2) في Railway: New > GitHub Repo > اختار الريبو
3) Variables: أضف PHONE_NUMBER برقمك (مثال 249912345678 بدون +)
4) أضف Volume وربطو بمسار /app/auth
5) افتح Logs وخذ "كود الربط" وادخلو في الواتس:
   الأجهزة المرتبطة > ربط جهاز > الربط برقم الهاتف

بعد الربط اكتب في أي شات:  !اوامر

ملاحظة: لازم يكون رقم البوت مشرف في القروب
عشان يشتغل الطرد والكتم والقفل وحذف الرسائل.
